# SKHY Light Edge AI & RF Fusion Node (Product ID: 900010)

## Technical Specifications

| Feature | Details |
|---------|---------|
| **Core Processor** | NVIDIA Jetson Orin Nano (8GB) |
| **SDR Platform** | Ettus USRP E310 (Embedded) |
| **AI Performance** | Up to 40 TOPS |
| **RF Tuning Range** | 70 MHz – 6 GHz |
| **Power Consumption** | ~28W (Orin Nano + E310 combined) |
| **Voltage Input** | 12V DC (Internal Voltage Regulation) |
| **Interfaces** | Common Power Port, Exposed GPIO/Peripherals for Orin Nano & E310 |

## Overview
The SKHY Light Edge AI & RF Fusion Node is a compact, high-efficiency system designed for tactical edge applications. By combining the low-power yet capable NVIDIA Orin Nano with the proven E310 SDR, it enables real-time signal processing and AI inference in a single, integrated enclosure.

## Key Features
- **Integrated Power Management**: A single 12V input powers both the AI board and the SDR through an internal precision regulator.
- **Developer Access**: While housed in a rugged casing, key pins for both the Orin Nano and E310 are exposed for custom hardware integration and debugging.
- **Edge Intelligence**: Ideal for signal classification, object detection, and lightweight RF-fusion tasks on drone platforms.
