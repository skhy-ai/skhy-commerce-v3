## Overview
The VC20 is a powerful ground command unit serving as the central hub for SKHY MANET networks. Equipped with four-band high-gain antennas, it provides long-range connectivity to airborne nodes and ground teams, enabling centralized command and control.

## Key Features
- **Centralized Management**: Monitors and controls the status of all nodes in the mesh.
- **Extended Range**: High-gain antenna array enables links to drones over 100km away.
- **Multi-Band Diversity**: Enhanced resilience against local interference and jamming.
- **Rugged Command Center**: Built for stationary or vehicle-mounted operation in harsh environments.
