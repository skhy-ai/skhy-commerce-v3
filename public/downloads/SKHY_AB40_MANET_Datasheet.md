## Overview
The AB40 is a long-range, high-altitude backbone radio designed for persistent wide-area mesh networking. It serves as the primary data relay for large-scale drone operations, connecting high-altitude platforms to ground command units over distances exceeding 100km.

## Key Features
- **Massive Range**: Optimized for air-to-ground and air-to-air links up to 200km.
- **Resilient Mesh**: Self-healing MANET architecture ensures connectivity even if nodes move or drop out.
- **Backbone Capability**: Supports high data rates for multiple HD video streams and telemetry fusion.
- **Rugged Design**: Industrial-grade housing for reliable operation on high-value UAVs.
